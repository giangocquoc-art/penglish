# PooEnglish product and interface guidelines

- Keep the learner's experience, clarity, and accessibility at the center of changes.
- Before upgrading an interface, inspect its current layout and capture the relevant screen at the target viewport. Identify visible usability defects and fix them as part of the work.
- Interface upgrades combine implementation with suitable visual assets. Create or refine component artwork before integrating it; do not make visual upgrades with code alone.
- Choose the mascot and pose for the specific learning context. Keep Bọt Biển present in bubble/heart feedback and preserve its encouragement, resting, and bubble effects where those states appear.
- Keep images, JavaScript, and CSS lightweight. Prefer optimized, content-hashed assets, avoid shipping unused art, and measure browser performance when a change could affect Vercel delivery or runtime smoothness.
- Review the result in screenshots at realistic mobile and desktop sizes, correct visible UX defects, and respect reduced-motion settings.
- Do not deploy to production unless the user explicitly asks.
